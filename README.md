# Cheese Toast

Jim Bumgardner's teapot-in-space arcade game (Mac 1993, CT II 1995, Windows
CT III 2003-04), ported to JavaScript and canvas. Play it at
https://ct.krazydad.com.

## Running locally

    /usr/bin/python3 tools/serve.py   # then open http://localhost:8080/

(Use the system Python: the macOS firewall blocks incoming connections to the
Homebrew ones, so an iPad on the LAN would get no answer.)

The server sends `Cache-Control: no-store` so an iPad always picks up fresh
files. Add `?debug` to the URL for cheat keys (J = Batboy, R = random bad
guy) and `window.ct` in the console.

## Controls

| Action | Keyboard | Touch |
|---|---|---|
| Turn | Left / Right arrows | the circle: point where to face (drag to keep steering) |
| Thrust | Z, X, Shift, Option | thrust |
| Fire (hold to autofire) | Space | fire |
| Shield | A, S, Up arrow, Ctrl | shield |
| Brake | Down arrow | double-tap the circle's middle (hold the second tap) |
| Pause | P or Esc | pause button |
| End game | Q | Pause, then End game |
| Sound on/off (remembered) | M | speaker button |
| Full screen | F | full-screen button |
| Settings (sound, volume, full screen, name tags, reduce motion, touch buttons, players per game, chat and mutes, bots in this game, controls) | | gear button |
| Zoom / roll / stats | + − / [ ] / ` | |

## Layout

- `js/game.js`: the game (port of CTGame: state machine, spawning, scoring,
  camera, rendering)
- `js/sprites.js`: sprite table and every creature's behavior (CTSprites.cpp)
- `js/sparks.js`, `js/stars.js`: explosion particles and the 3D starfield
- `js/font.js`: the original bitmap fonts with gradient tint and warp
- `js/sound.js`, `js/input.js`, `js/main.js`: audio, keyboard/touch, page glue
- `assets/`: generated by `tools/prepare_assets.py` from the CT_III source
  (not included in this repo)

## Shared Hall of Cheese

High scores are shared by everyone playing at ct.krazydad.com. `server/` holds
a small score server (Python standard library and SQLite) that the web server
proxies at `/api/`. New names are checked with TypeSafe's Jev model and must be
PG-13; a moderator page at `/mod/` (password protected) can edit, hide or
delete entries and override name verdicts. Without the server, as when running
locally, the game keeps scores on the device as before. To try it locally:

    TYPESAFE_API_KEY=... python3 server/scores_server.py --db /tmp/scores.db
    CT_API=http://127.0.0.1:3002 /usr/bin/python3 tools/serve.py

## Deploying

`tools/deploy.sh` copies the game (and, if asked, the score server and the
matchmaker) to a web server, locally or over ssh; see the comments at its top.
`server/*.service`, `server/turnserver.conf` and `tools/install-turn.sh` show an
example server setup (systemd services behind a web server that proxies `/api/`
and `/mm/`, plus coturn for the TURN relay). ct.krazydad.com deploys from a
private copy of this repository.

## Multiplayer

Pick **Solo**, **Co-op**, **Duel** or **Melee** on the top line in attract mode
(S / C / D / E) and start a game. Solo is a plain game of your own. Otherwise, if
someone is playing alone in the same mode, you join their universe (the
lowest-level one waiting); if not, you play alone until someone joins you.
**Games** on the top line (`/games/`) lists the games being played, with filters,
a Join button for each open one, and **+ New game** to start one of your own with
its settings. Both take you straight into the game, and back to the list when it ends. A universe at level 2 takes no newcomers.
The gear opens the settings: alone it pauses; in a shared universe your teapot
is frozen in place until you're back. Anyone in a game can switch off "Let bots join" there,
which sends away bots already in it and keeps the fill-in bots out. When one player runs out of pots they go back to
attract mode, and the player still flying waits for the next partner. Duels:
shooting the other teapot costs them a pot and scores 2000. On desktop, Enter
opens chat (speech balloons over the teapots). See MULTIPLAYER.md for the
design: the first player's browser hosts the game and sends snapshots to the
other over WebRTC; `server/match_server.py` only pairs players and relays the
connection setup. A guest's own teapot (and the camera, its shots and their
sounds) answers its keys at once, predicted, while the rest of the universe is
drawn a tick or two behind from a buffer of snapshots, so late or lost ones
don't show. The stats overlay (backquote) shows the round trip, snapshot gaps
and losses, how far ahead the prediction runs and the traffic. For testing,
`?netsim=RTT,JITTER,LOSS` makes a page's connections behave like a worse network
(e.g. `?netsim=160,40,0.03`) and `?nopredict` turns the prediction off.

Bots for testing live in `bots/` (Node + headless Chrome): `run-solo.mjs`
(fast, seeded single-player games) and `run-mp.mjs` (real-time multiplayer,
locally or `--online` through the test site). Policies: a hand-written baseline
and Jev (TypeSafe), which reads a symbolic view of the game (`js/agent.js`,
`?agent`) and picks the controls. `tools/render-video.py` turns a bot log into
a full-universe video.

## Notes on the port

- Collisions work across the universe's wrap-around seam (CT_III's quick box test didn't wrap, so
  nothing collided there; duel and melee starting points sit on seams).

- Saucers appear from level 0 and percolators (coffee pots) from level 1: CT_III had them the other way
  round, but the percolator re-aims and fires more often (every 2.25 s to the saucer's 2.7 s).

- Touch steering is a circle rather than turn buttons: the teapot turns toward where the thumb points,
  one heading step a tick, exactly as fast as a held arrow key.

Gameplay follows the CT_III C++ code tick for tick (20 ticks a second).
Rendering runs at the display rate and interpolates motion between ticks.
Deliberate departures from the original:

- Pause works (it was stubbed out), and the game pauses when the tab is hidden.
- High scores are shared online (see above), with localStorage as the offline
  fallback; the last engraved name is remembered.
- Explosion sparks fade out as intended; in CT_III a cast bug made them
  vanish after one tick.
- The teapot's firing position uses its heading when thrusting; CT_III read
  past the end of a 16-entry table.
- Bullets start at the spout tip. CT_III scaled its spout table to half the
  sprite size, so they started inside the pot, which showed at the 5 and 7 o'clock headings.
- Score digits roll a full cell (CT_III rolled about a quarter of one).
- The full screen, sound and pause buttons sit at the bottom right (bottom
  center while touch controls show). On desktop the radar moved to the lower
  left to make room; with touch controls it is at the top left. The radar has
  a faint gray rim.
- The motto verse is brighter; CT_III's navy-to-gray was hard to read.
- Attract mode opens on the instructions card and cycles instructions,
  beastiary, motto, Hall of Cheese (CT_III: Hall of Cheese, instructions,
  beastiary, motto, starting on the beastiary), so newcomers see the controls first.
- New creature: a quarter of the asterisks are "AI asterisks", the OpenAI and
  Claude logos joined and tumbling in opposite directions. Shot, they split
  into the two logos, mid-spin. The sheet (`assets/img/AILogos64.png`) is
  rendered by `tools/ai-logo-sprites.html` from Simple Icons outlines; the
  logos are trademarks of OpenAI and Anthropic.
- On short screens (phones in landscape), play zooms in up to 1.75x so about
  750 units fit across; the wide 800x600 fit made the teapot tiny. Attract
  screens keep the normal zoom.
- iPhone Safari has no full-screen mode for web pages, so there the
  full-screen button explains Add to Home Screen, which runs the game
  without browser bars.
- The name entry screen has a visible name box with a placeholder (and a keyboard
  icon on touch screens), clearer instructions, and an Engrave button that lights
  up once a name is typed. On phones it is larger and sits above the keyboard.
- The two whorls in the dusk clouds pull the teapot toward their centers
  (an idea from CT_III's to-do list): the pull starts a little outside each
  visible spiral and grows with the square of how deep you are. A graze bends your path a few degrees; a
  pass straight through more than doubles your speed. Asteroids, enemies and
  power-ups are pulled too (enemies that steer feel it as a nudge they can
  fight). New teapots never spawn inside a whorl.
- Three items from CT_III's own to-do list: a shield gauge, a short
  line under your own teapot while its shield is up (green, yellow, then red below 40, where the
  shield starts to sputter),
  asteroids and enemies never spawn on screen or just off it, and at most
  five chattering teeth are alive at once (they can't be shot).
- Phones and tablets held upright get a "turn your device sideways" screen,
  and a game in progress pauses. Full screen on Android locks landscape.
